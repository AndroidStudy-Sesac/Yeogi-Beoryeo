# 운영 공지 작성 및 표시 가이드

Firebase Remote Config의 운영 공지는 현재 발생 중인 장애 또는 기능 제한을 알리는 용도입니다. 설정 > 공지사항의 Firestore 공지와 데이터를 합치거나, Firestore 공지를 홈 긴급 배너로 표시하지 않습니다.

## 표시 정책

| 심각도 | 홈 | 영향 기능 화면 | 닫기 |
| --- | --- | --- | --- |
| `critical` | 표시 | 최우선 표시 | 제공하지 않음 |
| `warning` | 표시 | 일반 오류보다 우선 표시 | 동일 공지 ID를 숨김 |
| `info` | 표시 가능 | 기존 기능 흐름을 방해하지 않음 | 동일 공지 ID를 숨김 |

- 공지는 `affectedFeatures`에 포함된 기능에서만 표시합니다. 대상이 비어 있으면 홈 공지로 처리합니다.
- 사용자 닫힘 상태는 공지 ID별로 기기에 저장합니다. 새 ID의 공지는 기존 닫힘 상태와 관계없이 표시합니다.
- `critical` 공지는 닫기 상태가 있어도 표시합니다.
- 영향 기능에 대한 운영 공지가 활성화되어 있으면, 같은 장애를 설명하는 일반 오류 UI보다 운영 공지를 우선합니다.

## 문구 기준

공지에는 영향을 받는 기능, 현재 사용자 영향, 사용자가 할 수 있는 행동을 포함합니다. 복구 예상 정보는 확정된 경우에만 포함합니다.

API 키, 예외 원문, 서버 주소 등 내부 운영 정보, 담당자 개인 정보, 확인되지 않은 복구 시각은 포함하지 않습니다.

예시:

> 수거 장소 검색 일시 장애 안내
>
> 공공데이터포털 제공 API 연결 문제로 수거 장소 검색이 원활하지 않을 수 있습니다. 잠시 후 다시 시도해 주세요.
